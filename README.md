## 🎨 Design System & Accessibility

- **8-Point Spacing Grid:** Mathematically consistent layout rhythm and Golden Ratio proportions ($1:1.618$).
- **Dual Themes:** Midnight Engineering Blueprint (Dark) & Architectural Drafting Table (Light) with instant toggle and persistence.
- **Blueprint Drafting Grid:** Interactive grid overlay with millimeter tick marks and coordinate annotations.
- **Synthesized Audio:** Non-intrusive tactile feedback ticks via Web Audio API oscillators (toggleable from navigation).
- **WCAG 2.2 AA Baseline:** High contrast ratios, semantic HTML5 elements, and keyboard navigability (`⌘K`, `Esc`, `Tab`).
